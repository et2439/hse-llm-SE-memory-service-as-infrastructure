# Соответствие критериям КТ1 и КТ2

27.10.2026. Основание — [project.md курса](https://github.com/xufana/llm-system-engineering/blob/main/project.md) и [тема 15](https://github.com/xufana/llm-system-engineering/blob/main/topics.md). Нумерация разделов design doc соответствует таблице project.md; в отдельном шаблоне курса она отличается.

| Критерий | Материал и состояние |
|---|---|
| КТ1: разделы 1–2 | Клиент, задача, границы и измеримый контракт подготовлены |
| КТ1: раздел 3 | Численные бюджеты, SLO, допущения и стоимость альтернативы |
| КТ1: раздел 4 | Набросок схемы; готовый компонент — кандидат, интеграция не заявлена |
| КТ1: раздел 7 | 20 историй с контрольными вопросами и ожидаемым поведением |
| КТ1: одна страница | [Краткий контракт и бюджеты](kt1.md) |
| КТ1–КТ2: разделы 10–11 | Риски и открытые вопросы с ответственными и сроками |
| КТ2: уточнение контракта | Время, конфликт, забывание, права, повторы и ошибки |
| КТ2: раздел 7 | Полный набор, размер и классы, происхождение эталонов, метрики и связь с контрактом; версия и суммы зафиксированы в manifest |
| КТ2: видимая и отложенная части | 120 + 80 историй, отдельно 20 разработческих; закрытая часть не используется до КТ4 |
| КТ2: ground truth | Синтетические эталоны по конструкции до реализации; дополнительная проверка эталонов 40 заданий |
| КТ2: раздел 8 | Baseline и порядок усложнений описаны с условиями перехода; измерения относятся к КТ3 |

Ограничения синтетических шаблонов и применимость метрик описаны в методике. Оценку материалов выставляет преподаватель.
