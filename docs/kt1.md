# КТ1. Контракт и бюджеты

**Тема 15 — сервис памяти как инфраструктура.**

**Клиент.** Разработчик агента поддержки сохраняет между обращениями предпочтения, договорённости и неудачные попытки решения. Память должна оставаться актуальной, удаляться по просьбе и помещаться в контекст. Нагрузка: предполагаемые 5 команд, 1 000 пользователей, 10 000 операций/сутки, пик 3/с.

**Контракт.** Принимаем русские события и вопросы в авторизованной области. Возвращаем факты с источниками и статусом found/unknown/conflict/needs_clarification/denied. Учитываем исправления, время и срок действия. Подтверждённое забывание исключает целевой факт и связанные представления из будущей выдачи; старый повтор не восстанавливает его. Неоднозначное удаление требует уточнения. Инструкции внутри документов не меняют права. Контекст целиком ограничен переданным числом токенов. Повтор команды не дублирует эффект; ошибка не даёт ложного подтверждения.

**Границы.** Не гарантируем распознавание любой лжи разрешённого автора; не управляем копиями, уже переданными клиенту, и внешними резервными копиями.

| Бюджет | Предварительная цель |
|---|---|
| Качество | ≥90% историй; все контрольные вопросы истории должны пройти |
| Жёсткие проверки | 0 раскрытий удалённых/чужих сведений и превышений контекста на наборе |
| Отравление | Recall ≥90%, ложные тревоги ≤5%; обычные внешние источники включены |
| Контекст | До 2 048 токенов памяти с источниками |
| Задержка P95 | Чтение ≤0,8 с; запись ≤4 с; забывание ≤2 с |
| Доступность | 99,5% за 30 дней; 216 минут бюджета недоступности |
| Расходы | Оценка $104,11/мес. с запасом 30%; предел $120; отвечающий агент отдельно |

**Альтернатива.** Усечение последних сообщений истории: ориентир $13/мес. хранения с запасом. С одинаковым отвечающим агентом — $106,59 против $197,70 для сервиса. Экономическое преимущество пока не доказано.

**Проверка.** [20 историй](../eval/kt1_examples.jsonl): по два примера сохранения, изменения, времени, конфликтов, неизвестного ответа, длинного контекста, удаления, атак, обычных внешних источников и изоляции/повторов.

**Схема.** Агент → проверка прав → политики состояния → готовая память → фильтрация и упаковка. Версии и запреты — в БД; поиск и извлечение — готовый компонент.

**Открыто.** Подтвердить нагрузку, выбрать версию компонента, учесть ограничения синтетического набора, проверить конкурентное удаление. Подробные расчёты, источники тарифов и условия проверки — в [design doc](../design_doc.md).
