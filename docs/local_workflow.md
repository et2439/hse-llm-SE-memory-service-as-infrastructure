# Локальный комплект для PR: КТ1 и КТ2

Работа ограничена КТ1–КТ2. Артём и Владислав совместно отвечают за КТ1 и КТ2 в равных долях — по 50%. Перенос на GitHub и оформление PR выполняются вручную позже.

## 1. Состав КТ1

[Краткая страница](kt1.md), разделы 1–3 основного документа, набросок схемы, риски, открытые вопросы и 20 историй. Качество и задержка — цели; расходы — расчётный сценарий.

## 2. Ground truth КТ2

Эталоны заданы вместе с синтетическими историями до реализации сервиса. Завершена [проверка эталонов 40 заданий](../eval/annotations/reference_check/README.md). Ответственные за комплекты — Артём и Владислав, по 20 заданий.

Правила проверки статусов, значений, источников, атакующих событий и целей забывания приведены в [инструкции](annotation_guide.md).

## 3. Закрытый пакет

Файл .eval_private/kt2-holdout-closed.zip подготовлен локально. Его сумма и сумма исходных 80 историй фиксируются без чтения их содержания. Пакет не зашифрован и не входит в публичные архивы. Он предназначен для отдельной передачи преподавателю; факт внешней передачи не заявляется.

Повторная проверка упаковки без просмотра содержимого:

```sh
python3 -m eval.freeze --pack-closed
```

## 4. Фиксация и проверки

Актуальные версия и статус — в [manifest](../eval/manifest.json); доказательства фиксации — в [release](../eval/release.json). Фиксация проверяет происхождение эталонов, согласованность проверки эталонов, суммы закрытого пакета и сохраняет суммы методики. Метки историй при этом не переписываются.

```sh
python3 -m eval.validate
python3 -m eval.budget
python3 -m unittest discover -s tests -v
```

После фиксации изменения требуют новой версии. Внешняя передача пакета фиксируется отдельно после её выполнения.

## 5. Комплекты для публикации

```sh
python3 tools/prepare_checkpoints.py
```

В deliverables находятся CP-1.zip, CP-2.zip, два последовательных патча, тексты PR и TRANSFER.md. CP-1 содержит материалы КТ1, CP-2 — дополнение КТ2. Применимость патчей и валидаторы обоих срезов проверяются на временной копии; Git проекта не меняется.

Для сдачи: вручную перенести материалы, создать PR для каждой КТ, добавить преподавателя в ревьюеры и отправить ссылки в форму курса. Закрытую часть передавать отдельно. Порядок досдачи согласовывается с преподавателем.
