# Сервис памяти как инфраструктура

Тема 15 курса «Инженерия LLM-систем». Подготовлены материалы КТ1 и КТ2 для ручного оформления PR. Реализация сервиса и измерения относятся к КТ3.

Авторы материалов КТ1–КТ2: Жбанов Артём Игоревич (БПМИ2411) и Савченко Владислав Евгеньевич (БПМИ2410). Оба совместно отвечают за КТ1 и КТ2 в равных долях — по 50%. Комплекты проверки распределены поровну: по 20 заданий.

Начните с [краткой КТ1](docs/kt1.md), затем прочитайте [основной документ](design_doc.md) и [методику КТ2](docs/kt2.md). [Соответствие критериям](docs/submission_checklist.md).

## Материалы

КТ1: контракт, численные бюджеты, набросок архитектуры и 20 историй с вопросами.

КТ2: 200 синтетических историй — 120 видимых и 80 отложенных; ещё 20 разработческих примеров не оцениваются. Эталоны заданы по конструкции до реализации сервиса. [Протокол](eval/protocol.json), [manifest](eval/manifest.json) и [запись фиксации](eval/release.json) задают версию и контрольные суммы.

[Проверка эталонов 40 заданий](eval/annotations/reference_check/README.md) завершена; комплекты распределены по 20 для Артёма и Владислава. Процедура задания эталонов и правила оценки описаны в методике КТ2.

## Проверки

Python 3.10+, без внешних пакетов и ключа API:

```sh
python3 -m eval.validate
python3 -m eval.budget
python3 -m unittest discover -s tests -v
```

Проверяются данные, эталоны, смета, фиксация и упаковка. Качество будущего сервиса этими командами не измеряется. [Отчёт](docs/validation_report.md).

## Ручной перенос

[Локальный порядок](docs/local_workflow.md) описывает закрытый пакет и подготовку CP-1/CP-2. `python3 tools/prepare_checkpoints.py` собирает архивы, последовательные патчи, тексты PR и инструкцию переноса. Ветки, коммиты, PR и публикации автоматически не создаются.

Закрытая часть, личные бланки, окружение и отложенные заготовки КТ3 исключены из публичных комплектов. Внешняя передача закрытого пакета пока не подтверждена; его содержимое не используется до КТ4.
