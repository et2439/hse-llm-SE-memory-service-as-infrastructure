# Сервис памяти как инфраструктура

Тема 15 курса «Инженерия LLM-систем». Материалы КТ1 и КТ2.

## Материалы

- [КТ1: краткий контракт и бюджеты](docs/kt1.md) — клиент, обещания сервиса, численные цели и альтернатива.
- [Design doc](design_doc.md) — контракт, смета, набросок архитектуры, метрики, baseline, риски и открытые вопросы.
- [КТ2: методика оценки](docs/kt2.md) — состав набора, эталоны, правила сравнения и план усложнений.
- [Набор и формат данных](eval/README.md) — 120 видимых историй, 20 разработческих примеров и поднабор из 20 историй КТ1.
- [Проверка 40 заданий](eval/annotations/reference_check/README.md) — результаты и обоснования.

Полный оцениваемый набор содержит 200 историй. Отложенные 80 историй хранятся отдельно, не используются для настройки и открываются только при итоговом оценивании. Версия набора и контрольные суммы находятся в [manifest](eval/manifest.json), условия оценки — в [протоколе](eval/protocol.json), фиксация — в [release](eval/release.json).

## Проверки

Python 3.10+, стандартная библиотека:

```sh
python3 -m eval.validate
python3 -m eval.budget
python3 -m unittest discover -s tests -v
```

Команды проверяют данные, эталоны, контрольные суммы и расчёт бюджета. Числа качества и задержки в документах — цели, расходы — плановый расчёт; результатов испытания сервиса в материалах КТ1–КТ2 нет.
