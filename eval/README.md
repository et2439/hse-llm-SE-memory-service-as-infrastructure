# Первые 20 историй КТ1

[kt1_examples.jsonl](kt1_examples.jsonl) содержит события, контрольные вопросы и ожидаемое поведение. В каждой из десяти категорий по две истории; всего 24 вопроса. category и contract_ids связывают пример с контрактом.

## Формат

- events — входные события; поля delivery_id, id, op, at, channel, scope, text и необязательный expires_at.
- scope — tenant, subject, namespace; канал user/document/tool назначает авторизованный адаптер.
- checks.after_event — число доставленных событий перед вопросом.
- checks.input — вопрос с областью, текущим временем и бюджетом контекста.
- checks.expected и oracle — эталоны проверяющего; их нельзя передавать агенту.

Исправление оценивается по времени утверждения, а не порядку доставки. На границе срока факт уже недоступен. В вопросах удаления проверяются наличие факта до просьбы forget и сохранность остальных сведений после неё.

## Проверки

```sh
python3 -m eval.validate
python3 -m eval.budget
```

В [manifest](manifest.json) находятся контрольные суммы. Проверка структуры не измеряет качество сервиса.
